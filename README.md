# Ayuntamiento de Cazorla (Portal de Incidencias)

## Objetivo

Proyecto desarrollado para la asignatura de **Sistemas de Información Basados en Web** de 2º de Ingeniería Informática.
Para este proyecto, se ha pedido desarrollar un **portal web** que permita administrar **incidencias** de un Ayuntamiento, para ello se hará uso de diferentes lenguajes tales como **HTML5**, **CSS3**, **JS**, **PHP** entre otros.

> Todo lo relacionado con este proyecto se irá actualizando con respecto a las prácticas propuestas por el profesor.
